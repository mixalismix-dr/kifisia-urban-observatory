# Kifisia Urban Observatory

A 3D open-data atlas of **Kifisia municipality**, including Kifisia, Nea Erythraia and Ekali. It combines mapped buildings, tree cover, transport, waterways, land cover, terrain and local places. Source links sit beside their corresponding map layers.

**[Open the live map](https://mixalismix-dr.github.io/kifisia-urban-observatory/)**

## Run locally

Requires Node.js 20.19+.

```sh
npm install
npm run dev
```

Open the URL printed by Vite. `npm run build` creates the static site in `dist/`.

To refresh the committed boundary:

```sh
npm run data:boundary
```

This command makes one Nominatim lookup and writes the result to `public/data/`. The public site reads the committed file and makes no Nominatim requests.

To rebuild the tree image and bus-stop clip, run `powershell -ExecutionPolicy Bypass -File scripts/prepare-open-data.ps1` on a machine with QGIS 3.40.9 installed. The script downloads the Athens GIS source files, clips them with GDAL, and writes the derived files to `public/data/`. Source downloads stay in `scripts/downloads/`, which is ignored by Git. If the municipality boundary changes, update the image coordinates in `src/main.js` from `gdalinfo scripts/downloads/tree_kifisia.tif`.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-cycleways.ps1` to refresh the Kifisia-centre bike extract. Its fixed bounding box and the 19-segment result make the partial coverage inspectable. The script parses OSM ways with `highway=cycleway` or a lane/track `cycleway*` tag, then clips them to the municipal boundary.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-sports-buildings.ps1` to refresh sports footprints and tagged building types. It downloads the latest Geofabrik Greece OSM extract, selects relevant polygons with GDAL, clips them to the municipal boundary and writes two small GeoJSON layers. Update the snapshot date in the interface and source attribution when refreshing. The bus icon is drawn in `public/bus-3d.svg`; `scripts/render-bus-icon.py` renders the PNG used by MapLibre with QGIS Python/PyQt5.

Run `& 'C:\Program Files\QGIS 3.40.9\bin\python-qgis-ltr.bat' scripts/prepare-greenery.py` in PowerShell to rebuild the 3D greenery points. The script reads the existing Copernicus tree-cover clip, downloads the relevant [Meta/WRI CHMv2 cloud-optimized tile](https://registry.opendata.aws/dataforgood-fb-forestsv2/) when needed, and retains its large clipped raster only in the ignored `scripts/downloads/` directory. The committed GeoJSON contains only representative canopy forms. It does not reconstruct individual crowns or prove individual tree positions. A local open LiDAR point cloud covering Kifisia was not verified; [EuroSDR's 2026 review](https://www.eurosdr.net/sites/default/files/uploaded_files/pub78_pointclouddialects_2026-02.pdf) also reports no open-access national Greek point-cloud dataset.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-atlas.ps1` to rebuild the landscape, land-cover, civic and DSM layers. The script downloads the public Athens GIS files and Copernicus GLO-30 tile, clips them with QGIS/GDAL, and rebuilds the small point collections with Node.js. Source downloads stay in ignored `scripts/downloads/`. Run `npm run check:data` afterward.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-added-layers.ps1` to rebuild traffic lights, mapped public spaces, KAEK parcels and the NDVI image. It requires QGIS 3.40.9, Node.js and internet access. The fixed Cadastre ZIP and Sentinel-2 scene reproduce the displayed dates; update their source URLs and the map labels together when refreshing. The Attica ZIP is about 153 MB and stays in ignored `scripts/downloads/`. Run `npm run check:data` afterward.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-flood.ps1` to refresh the official Attica flood polygon. It discovers the public 100-year FeatureServer layer from the Water Directorate web map, repairs its geometry, clips it to Kifisia and writes `public/data/kifisia-flood-100.geojson`.

Run `node scripts/prepare-metro.mjs` to refresh the Athens GIS Line 1 track and stations. The script orders station points along the Kifissia–Piraeus line and checks the two terminals.

Run `powershell -ExecutionPolicy Bypass -File scripts/prepare-traffic-roads.ps1` to rebuild the local drivable-road geometry from the Geofabrik extract with QGIS/GDAL. Run `node scripts/build-bus-network.mjs` to rebuild the 26 line shapes from the public OASA GTFS snapshot used by the bus details. Update the source dates in the interface when either snapshot changes.

## Design

The map is the product. A compact side panel gives context, district shortcuts, layer switches, source links and details for selected features. The interface draws on the inspectable-building approach of the [Helsinki 3D urban data model](https://www.hel.fi/en/decision-making/information-on-helsinki/maps-and-geospatial-data/helsinki-3d). The live bus switch adds a small ARGOS-like moving layer without disguising its community provenance or age. Procedural 3D buses sit on the map plane at the feed's reported coordinates, with their fronts turned to the reported bearing (clockwise from north). Their white, blue and yellow scheme follows local OASA vehicles. Models are enlarged at city zoom for legibility, so their size is not a measurement. A vehicle without a bearing appears as a dot. The live feed does not identify each vehicle's make or model, and a stopped bus may retain an older bearing. The earlier `bus-3d.svg`/PNG serves as a fallback if 3D rendering is unavailable.

The sidebar search uses a committed local index of 1,068 Kifisia locations: 765 named OSM streets, 189 distinct mapped OSM addresses, and selected named parks, civic places, landmarks, sports sites, historic sites and Kifissia station. Search matches Greek text with or without accents. Street results use a representative point from the longest mapped segment; address locations reflect OSM mapping and may be incomplete. The search makes no external geocoding requests. Refresh the index with `powershell -ExecutionPolicy Bypass -File scripts/prepare-search.ps1` on a machine with QGIS 3.40.9 and Node.js. The script refreshes the Geofabrik OSM extract if it is missing, clips streets and address points to the municipal boundary, then runs `scripts/build-search-index.mjs`.

The opt-in sun preview uses [SunCalc](https://github.com/mourner/suncalc) for the sun's position in Athens local time and MapLibre's map-anchored building light. At zoom 16 and above, it draws approximate ground shadows from 17,675 OSM building footprints clipped to Kifisia. Heights for 15,527 footprints come from the [Copernicus Urban Atlas 2021 Building Block Height](https://land.copernicus.eu/en/products/urban-atlas?tab=datasets), a 10 m raster hosted by [Athens GIS](https://athensgis.gr/). Two footprints use OSM height tags; the remaining 2,146 assume 8 m. The 10 m block values are samples at footprint centroids, not measured heights for individual buildings. Shadow geometry is a flat-ground convex hull of each footprint and its projected offset; lengths are capped at 60 m. It excludes trees, terrain, and roof shapes. The result is an illustrative view, not a surveyed solar-access or heat model. MapLibre's extrusions do not currently cast ground shadows natively ([style-spec proposal](https://github.com/maplibre/maplibre-style-spec/issues/1797)). Rebuild the footprint file with `scripts/prepare-sports-buildings.ps1` (QGIS 3.40.9 and Node.js required).

The three place stories draw on the [municipal tourism guide](https://www.kifissia.gr/sites/default/files/arxia/touristikos%20odigos%20kifissias%20el.pdf), the [museum's history](https://www.gnhm.gr/en/the-museum/founders-and-history/), and [municipal attractions](https://kifissia.gr/axiotheata/). Their resized photos are by [C messier](https://commons.wikimedia.org/wiki/User:C_messier), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/): [Άλσος Κηφισιάς](https://commons.wikimedia.org/wiki/File:Άλσος_Κηφισιάς_4106.jpg), [Goulandris Museum](https://commons.wikimedia.org/wiki/File:Μουσείο_Γουλανδρή_7886.jpg), and [Villa Kazouli](https://commons.wikimedia.org/wiki/File:Βίλα_Καζούλη_7942.jpg). Photo dates appear in the story cards; they do not depict current conditions.

## Code map

- `src/main.js`: map setup and interactions.
- `src/sun-preview.js`: Athens sun position and illustrative building shadows.
- `src/train-layer.js` and `src/rail-estimates.js`: schematic moving Line 1 trains and indicative positions.
- `src/traffic-layer.js`: illustrative moving cars on mapped roads.
- `src/style.css`: layout and visual styling.
- `scripts/fetch-boundary.mjs`: reproducible boundary download.
- `scripts/prepare-open-data.ps1`: reproducible tree-cover and bus-stop clipping.
- `scripts/prepare-greenery.py`: reproducible canopy-form extraction from modeled heights and tree cover.
- `scripts/build-sun-buildings.py`: sample the 2021 building-block height raster at local OSM footprints.
- `scripts/prepare-search.ps1`: local OSM street and address extraction for search.
- `scripts/prepare-cycleways.ps1`: reproducible OSM bike-facility extraction for Kifisia centre.
- `scripts/prepare-atlas.ps1`: reproducible Athens GIS and Copernicus terrain extract.
- `scripts/prepare-flood.ps1`: reproducible Attica Water Directorate flood-plan extract.
- `scripts/build-atlas-pois.mjs`: small civic and landmark point collections.
- `public/data/`: committed clipped GeoJSON and raster overlays.

No application server or API key is required. The map needs internet access for OpenFreeMap tiles and the MapLibre base style.
